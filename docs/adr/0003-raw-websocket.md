# ADR 0003. STOMP 없이 WebSocketHandler를 직접 구현한다

- 상태: 확정
- 결정일: 2026-11-22
- 관련 문서: [05-PROTOCOL.md](../05-PROTOCOL.md)

## 고른 것

`WebSocketHandler` 직접 구현

## 버린 대안

STOMP + 메시지 브로커

## 이유

- 필요한 것은 연결별 순서 보장, 묶음별 ack, 종료 코드다.
- STOMP의 구독 모델은 문서 세션이 직접 연결 목록을 들고 있는 구조와 겹친다.

## 감수하는 것

- 메시지 파싱, 연결 관리, 재접속 규칙을 직접 만든다.

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.
