# ADR 0001. 동시 편집은 서버 주도 OT로 푼다

- 상태: 확정
- 결정일: 2026-11-13
- 관련 문서: [04-OT-DESIGN.md](../04-OT-DESIGN.md)

## 고른 것

서버 주도 OT

## 버린 대안

CRDT (Yjs, Automerge)

## 이유

- 권한 검사, 연산 로그, 버전 기록 때문에 어차피 중앙 서버가 필요하다.
- 서버가 순서를 정해 주면 변환 규칙이 단순해지고, 참여자별 메타데이터를 문서에 쌓지 않는다.
- 라이브러리를 가져다 쓰면 핵심 문제를 직접 푼 흔적이 남지 않는다.

## 감수하는 것

- 서버 없이는 합칠 수 없다.
- 긴 오프라인 편집은 CRDT보다 약하다 (7일, 5,000개 한도)

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.
