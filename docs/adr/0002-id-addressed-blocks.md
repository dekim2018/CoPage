# ADR 0002. 블록은 ID로 가리키고 블록 안만 텍스트 OT를 쓴다

- 상태: 확정
- 결정일: 2026-11-22
- 관련 문서: [04-OT-DESIGN.md](../04-OT-DESIGN.md)

## 고른 것

블록은 ID 주소, 블록 안만 텍스트 OT

## 버린 대안

문서 전체를 경로 기반 JSON OT로

## 이유

- 경로 기반은 연산 종류의 모든 쌍에 변환이 필요하고, 트리 이동의 변환이 특히 어렵다.
- ID 주소는 이동, 삭제, 속성 변경에서 변환을 없앤다.

## 감수하는 것

- 일부 충돌을 변환으로 풀지 못하고 거부한다 ([ADR 0012](./0012-nack-on-structural-conflict.md))

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.
