# ADR 0009. OT 코어는 Java와 TypeScript로 각각 구현하고 적합성 벡터로 맞춘다

- 상태: 확정
- 결정일: 2026-11-22
- 관련 문서: [11-TEST-PLAN.md](../11-TEST-PLAN.md)

## 고른 것

Java와 TypeScript 두 구현 + 적합성 벡터

## 버린 대안

한 언어로 짜서 양쪽에서 실행 (Java를 브라우저용으로 변환하거나 서버에서 JavaScript 실행)

## 이유

- 변환 도구를 거치면 브라우저 번들이 커지고 디버깅이 어렵다.
- 서버에서 JavaScript를 돌리면 "Java로 구현"이라는 결정과 어긋난다.

## 감수하는 것

- 같은 규칙을 두 번 쓴다.
- 벡터가 놓친 조합에서 두 구현이 다를 위험이 남는다.

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.
