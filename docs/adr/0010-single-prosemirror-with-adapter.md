# ADR 0010. 편집기는 ProseMirror 하나에 어댑터를 붙인다

- 상태: 확정
- 결정일: 2026-11-22
- 관련 문서: [10-FRONTEND.md](../10-FRONTEND.md)

## 고른 것

ProseMirror 하나 + 어댑터

## 버린 대안

블록마다 따로 떨어진 입력 영역

## 이유

- 블록별 입력 영역은 여러 블록에 걸친 선택, 복사, 방향키 이동을 전부 직접 만들어야 한다.

## 감수하는 것

- 위치 체계를 양방향으로 바꾸는 어댑터가 필요하다.
- 0단계에서 안 되면 이 대안으로 돌아간다.

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.
