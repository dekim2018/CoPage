# ADR 0012. 일부 구조 충돌은 변환하지 않고 거부한다

- 상태: 확정
- 결정일: 2026-11-22
- 관련 문서: [04-OT-DESIGN.md](../04-OT-DESIGN.md)

## 고른 것

일부 구조 충돌은 거부 후 되돌림

## 버린 대안

모든 충돌을 변환으로 해소

## 이유

- 이동과 합치기, 이동과 이동의 순환까지 변환으로 풀면 규칙 수가 크게 늘고 검증이 어렵다.
- 거부는 규칙이 단순하고 항상 수렴한다.

## 감수하는 것

- 드물게 방금 한 입력이 취소된다.
- 빈도를 거부율 지표로 감시한다.

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.

## 후속

- 2026-11-24: 거부 규칙은 그대로 두고, 거부된 묶음에서 구조 편집이 섞이지 않은 블록의 편집은 클라이언트가 살려 다시 보낸다. 못 살린 글은 보관함에 보인다([ADR 0017](./0017-salvage-rejected-edits-per-block.md), D-27). "감수하는 것" 의 "방금 한 입력이 취소된다" 가 구조 편집과 그 블록의 편집으로 좁혀졌다.
