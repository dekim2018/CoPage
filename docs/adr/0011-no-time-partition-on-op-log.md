# ADR 0011. 연산 로그는 시간 범위 파티션을 나누지 않는다

- 상태: 확정
- 결정일: 2026-11-22
- 관련 문서: [06-DATA-MODEL.md](../06-DATA-MODEL.md)

## 고른 것

연산 로그 단일 테이블

## 버린 대안

시간 범위 파티션

## 이유

- 파티션 키가 유일 제약에 들어가야 해서 (문서, 리비전) 유일 보장이 깨진다 (8.4)

## 감수하는 것

- 오래된 로그를 배치 DELETE로 지워야 한다.

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.
