# ADR 0006. 댓글 위치는 글자 서식으로 표현한다

- 상태: 확정
- 결정일: 2026-11-22
- 관련 문서: [08-FEATURES.md](../08-FEATURES.md)

## 고른 것

댓글 위치를 글자 서식으로

## 버린 대안

댓글 테이블에 (블록, 시작, 끝)을 저장하고 편집마다 갱신

## 이유

- 테이블 방식은 모든 텍스트 연산마다 그 블록의 댓글 행을 고쳐야 한다.
- 서식 방식은 이미 있는 변환 규칙이 위치를 옮겨 준다.

## 감수하는 것

- 댓글을 달면 문서 리비전이 올라간다.
- 댓글 권한자의 연산을 따로 검사해야 한다.

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.
