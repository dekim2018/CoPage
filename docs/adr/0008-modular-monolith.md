# ADR 0008. 서버는 모듈형 단일 서버로 만든다

- 상태: 확정
- 결정일: 2026-11-22
- 관련 문서: [03-ARCHITECTURE.md](../03-ARCHITECTURE.md)

## 고른 것

모듈형 단일 서버

## 버린 대안

MSA

## 이유

- 팬파라이브가 이미 MSA다.
- 이 프로젝트의 어려움은 서비스 사이가 아니라 문서 세션 안에 있다.
- 권한 검사를 편집 경로에서 네트워크 호출 없이 한다.

## 감수하는 것

- 모듈별로 따로 배포하거나 확장할 수 없다.

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.

## 후속

- 2026-11-24: 모듈 경계는 Spring Modulith 대신 ArchUnit 시험으로 지킨다([ADR 0018](./0018-module-boundaries-with-archunit.md), D-32). 지금 모듈은 `identity`, `workspace`, `permission`, `collab` 이다.
