# ADR 0004. 한 문서는 한 노드가 소유한다

- 상태: 확정
- 결정일: 2026-11-13
- 관련 문서: [03-ARCHITECTURE.md](../03-ARCHITECTURE.md)

## 고른 것

문서를 한 노드가 소유

## 버린 대안

모든 노드가 편집을 받고 Redis pub/sub으로 서로 방송

## 이유

- 여러 노드가 같은 문서의 순서를 정하려면 매 묶음마다 분산 락이나 DB 재시도가 필요하다.
- 한 노드가 메모리에서 순서를 정하면 편집 경로에 락이 없다.

## 감수하는 것

- 소유권 이전 절차가 필요하다.
- 노드가 죽으면 그 노드의 문서는 리스 만료까지 멈춘다.

## 다시 검토할 조건

13장의 부하 측정과 장애 실험 결과가 이 결정의 전제와 다르게 나오면 이 문서를 고치고 상태를 "대체됨"으로 바꾼다.

## 후속

- 2026-11-23: 리스에 펜싱 토큰은 붙이지 않고 연산 로그의 기본 키를 펜스로 쓴다([ADR 0013](./0013-primary-key-as-fence.md), D-04).
- 2026-11-24 기준 구현은 노드 1대다. 리스, 양도, 프록시 해시는 로드맵 4단계에서 만든다. 노드 한 대를 `kill -9` 하고 다시 띄우면 편집 재개까지 p99 4.4~6.3초였다([CHAOS.md](../CHAOS.md)). 다른 노드가 넘겨받는 경우는 아직 재지 않았다.
